# TechMarbles Odoo Apps — Shopify Connector

Source repository for [apps.odoo.com](https://apps.odoo.com) submissions.

Each branch targets one Odoo series (`16.0`, `17.0`, `18.0`, `19.0`); the
module `techmarbles_shopify_connector/` sits at the branch root, as the store
scanner requires. The module is a store-listing package (manifest +
description page); the sync itself runs in the TechMarbles cloud service and
the Shopify app: https://apps.shopify.com/odoo-integrator
